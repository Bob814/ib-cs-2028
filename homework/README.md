# Homework submission rules

Put **all Python homework files in this `homework/` folder**. Use one Python file per assignment, unless your teacher says otherwise.

## File names

Use this pattern:

```text
<student-name>-<homework-name>.py
```

For example:

```text
homework/anna-petrova-homework-01.py
```

- Use **lowercase letters** and **hyphens**, not spaces.
- Include your name and the homework name or number.
- Keep the `.py` extension.
- Do not change other students' files.

## Before submitting

- [ ] My file is in `homework/` and has the correct name.
- [ ] I used a **new branch** for this assignment.
- [ ] I committed and pushed only my homework changes.
- [ ] My Pull Request targets the teacher's original repository (`main`).

See the [main README](../README.md) for fork, branch, and Pull Request instructions.
