# Computer Science — Python Homework

Submit your Python homework through **Pull Requests** to this repository. Each assignment goes in a separate branch of your own fork.

## Getting started (once)

1. Follow [INSTALLATION.md](INSTALLATION.md) to set up Python, Git, VS Code, and GitHub integration.
2. On GitHub, click **Fork** on this repository to create your own copy.
3. In your fork, click **Code → HTTPS** and copy the URL.
4. In VS Code, open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and choose **Git: Clone**. Paste the URL, select a local folder, and open the project.

## For each homework

1. Update your fork: on GitHub, switch to your fork's `main` branch and select **Sync fork → Update branch**. In VS Code, switch to local `main` and **Pull**.
2. Create a **new branch from `main`** (VS Code: click the branch name in the bottom-left corner → **Create new branch**). For example: `anna-petrova-homework-01`.
3. Add your solution as described in [homework/README.md](homework/README.md).
4. In VS Code's **Source Control**, stage your file (`+`), enter a commit message, and click **Commit**.
5. Click **Publish Branch** (or **Push**) to upload it to your fork.
6. Open your fork on GitHub, choose **Compare & pull request**, and create a PR with:
   - **Base:** teacher's original repository, `main`
   - **Compare/head:** your fork, your homework branch

**Important:** Pushing is not enough — your assignment is submitted when you create the **Pull Request**.

## After feedback

To make corrections, switch back to the same homework branch, edit your file, then **Commit** and **Push**. The existing Pull Request will update automatically; do not create a second PR.
