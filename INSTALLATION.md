# Installation and setup

Complete these steps **once** before your first homework.

1. **GitHub account:** Sign up or sign in at [github.com](https://github.com/).
2. **Python:** Install Python from [python.org/downloads](https://www.python.org/downloads/). On Windows, make sure Python is available from the command line (for example, select **Add Python to PATH** if offered).
3. **Git:** Install Git from [git-scm.com/downloads](https://git-scm.com/downloads).
4. **VS Code:** Install Visual Studio Code from [code.visualstudio.com](https://code.visualstudio.com/).
5. **VS Code extensions:** Open **Extensions** in VS Code and install:
   - **Python** (Microsoft)
   - **GitHub Pull Requests** (GitHub; sometimes listed as *GitHub Pull Requests and Issues*)
6. **GitHub sign-in:** In VS Code, use the **Accounts** menu to sign in to GitHub and approve the authorization in your browser.
7. **Git identity:** Open **Terminal → New Terminal** in VS Code and enter (using your own details):

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"
   ```

These Git settings identify your commits; signing in to GitHub is a separate step.
